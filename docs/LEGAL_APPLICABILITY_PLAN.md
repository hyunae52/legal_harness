# 사건 적용 근거 정책 구현 계획

2026-09-28. 기준 main: 58542cc583d5b65d101c34c3c914872be054a3d3.

사용자가 승인한 방향: 사실·쟁점·역할별 날짜를 확인하고 사건에 적용되는 법령과 부칙을 기준으로 판례·해석례를 교차 검토한다. 자료 검색 순서는 자유롭다. 사건 이후 나온 판결도 그 사건에 적용되는 구법을 해석한 자료라면 검토한다. 선고일/발행일과 법령 적용 시점을 혼동하지 않는다.

## 변경 계약

- 연구 검토에 `legal_basis`를 추가한다. 적용 법령의 실제 본문 인용, 서버가 관측한 버전, 날짜 역할, 적용 이유, 부칙/개정 검토, 판례/해석례의 적용 관계와 후속 심급/변경 검토를 연결한다.
- 기존 입력은 구문 오류로 거절하지 않는다. 새 연결을 생략하면 공백으로 반환한다. 확정 결론은 blocked, 공백과 후속 확인을 설명한 조건부/유보는 needs_info다.
- 법령 버전은 조회 영수증의 해당 passage/unit과 비교한다. 임의로 올린 문자열이나 다른 연구의 자료를 공식 원문으로 승인하지 않는다.
- 판례·심사/심판 결정·행정해석은 별도 종류로 선언한다. 같은 규정/관련 부분 유지/다른 규정/미확인을 구분한다. 적용 불가 자료를 직접 근거로 제출하는 모순을 검사한다. 출처의 이름이나 날짜만으로 결론의 승자를 계산하지 않는다.
- 반론을 해결했다고 제출할 때 이를 뒷받침하는 원문 인용도 제출한다. 배제한 자료와 이유를 보존한다.
- korean-law-mcp 4.14.2의 실제 `판시사항:`/`참조조문:`/`전문:` 본문 형식도 인식한다. 요약/검색 목록을 완전한 본문으로 승격하지 않는다.
- 정책 버전을 올리고 MCP/Actions 설명에 같은 기준을 전달한다. 원문 실존과 연결 검사는 결정론적으로 수행하되 법률적 타당성은 계속 unverified다. LLM의 의미 판단을 독립 검수 통과로 표시하지 않는다.
- 일반 도구 조회, 접속 정책, 사용량 한도, upstream 프로세스, PR 동의·머지 권한은 이 변경의 대상이 아니다.

## 검증 및 전달

고정 합성 자료로 누락·버전 위조·반론 근거 위조·구법/신법 혼동·상급심 처리 미확인·사건 이후 판결 허용을 RED→GREEN으로 확인한다. 기존 REST/MCP/Actions 회귀, 설치 패키지, Pro 독립 검토를 수행한다. 법률 정답 검증과 구조 검증의 범위를 구분한다. 검수 가능한 PR을 만들고 운영 적용 여부는 실제 배포 증거와 구분해 기록한다.
