# korean-law-mcp 4.15.5 적용

법령 엔진을 공식 npm `korean-law-mcp@4.15.1`에서 `4.15.5`로 올린다. `package.json`과 두 잠금 파일을 함께 갱신하고, 원작자가 고정한 별표 파서 `kordoc@4.18.2`를 사용한다. 다른 의존성 버전과 stdio 연동, 연구·검수 규칙은 유지한다.

[공식 릴리스](https://github.com/chrisryugj/korean-law-mcp/releases/tag/v4.15.5)에는 4.15.2~4.15.5의 판례 사건번호 매칭, 본문 누락·줄바꿈, 과거 시행본 선택, 조문·별표 번호, 취소·호출 한도 처리 수정이 포함된다. 이 변경에 맞춰 기존 연혁·별표 실조회 시험에 정확한 사건번호 검색과 실제 판결 전문 조회를 추가했다.

세법 엔진은 `hyunae52/korean-taxlaw-mcp`의 `2.1.0.post1` / `16a08b9af70f49fc60a5f54ab0f9812be206c8f5`를 유지한다. 2026-10-04 확인 시 원작자 main `a91872fed2c12cd51fffdc4c2dbbfcabe997262b`를 이미 포함하고 있어 추가로 동기화할 원작자 변경이 없었다.

## 운영 적용 절차

조회 엔진 교체는 보호된 배포 항목이다. 정확한 후보의 GitHub Review 성공을 확인한 뒤 기존 rollout gate로 유입 차단 → 요청 종료 대기 → 제공자 선택 전환 → 실제 MCP 검사 → 유입 재개를 수행한다. 이전 4.15.1 설치본과 선택 설정은 복구용으로 보존한다. 선택 manifest와 자동 배포기 law_version 기준도 함께 검증·갱신한다.

그 다음 main 병합의 Review와 자동 Deploy를 확인하고, 공개 `/health`에서 앱 커밋·법령 4.15.5·세법 2.1.0.post1 및 기존 연구 정책을 대조한다. 공개 MCP에서도 판결·과거 법령·별표·세법 조회를 확인한다. 배포 완료 여부는 해당 PR의 실제 Actions와 공개 운영 확인 기록으로 별도 확정한다.

매일 한국시간 03:30의 upstream 확인 일정은 유지하고, 반영 후 알림 발송 없이 한 번 실행해 설치 버전 인식까지 확인한다.

후보 설치 전 디스크 부족은 사용이 끝난 회전 로그 한 개를 무손실 압축해 해결했다. 압축 전·해제 후 SHA-256을 대조했으며 현재·복구 릴리스나 활성 로그를 지우지 않았다. 운영 디스크 여유는 계속 관리가 필요하다.
