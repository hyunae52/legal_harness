## N-1. 원문 요약의 적용조건 누락

`raw_lookup_only-1`은 국세청 검색 4회와 문서 읽기 1회로 기획재정부 재산세제과-512(2021-05-25)를 확보했다. 원래 회신과 별첨도 실제 반환 본문에 포함돼 있었다. 문서번호·회신일·공식 링크·직접 인용·해당 사례의 2년 결론은 정확했다. 원문을 읽지 않았거나 별첨을 창작한 실패는 아니다.

모델은 별첨의 판정 절차를 부연하면서 **조정대상지역이라는 적용 전제**를 전혀 드러내지 않았다. 원문은 정해진 시점의 지역 요건을 충족하지 않으면 3년으로 결과가 달라지므로, 이 생략은 일반 절차의 대상 범위를 넓힌다. 단순 조회·직접 인용이 정확해도 부연 설명의 중요한 의미 오류는 실패다. 비조정지역도 2년이라고 명시적으로 단정했다거나, 모든 생략을 자동 실패로 보았다고 과장하지 않는다.

이 응답과 원문 조건을 SSS에 별도 대조했고 [동일한 FAIL 판정](AUTHORITY_RAW_FIDELITY_SSS_RESPONSE_2026-10-02.txt)을 받았다. 앞선 pilot-k의 고가주택 제외 누락과 같은 출처 충실성 기준이다. 원본을 유지하며 재시험 성공으로 덮지 않는다.

전역 조건 보존 안내는 이미 존재했다. [후속 보완안](../AUTHORITY_RAW_LOOKUP_FIDELITY_PLAN.md)은 원문을 복제하거나 의미 조건을 추출하지 않고, 도구 결과 가까이에 같은 문서의 전제·회신을 읽는 안내와 실제 필드 참조를 제공하는 것이다. [SSS 검토](AUTHORITY_RAW_REMEDIATION_SSS_RESPONSE_2026-10-02.txt)는 이를 최소 후보로 권고했지만 구현·모델 효과를 승인한 것은 아니다.

## N-2. 검수 입력 수정 중 시간 초과

`remaining_two_homes-2`는 고정된 1,500초 안에 최종 답변이 없었다. MCP 63회 중 오류 응답 13회가 있었고, 성공한 연구는 하나였다. 새 연구로 예산을 초기화하지 않았다. 핵심 대법원 2024두55426과 현행 제155조 본문을 실제로 확보했으므로 최초 사건번호 미발견과는 다른 실패다.

| 관측 위치 | 실제 관측 |
| --- | --- |
| 호출 38~43 | 요건 근거 입력의 누락·잘못된 인용·프로필 요구 거절 뒤 일부 평가를 수정했다. |
| 호출 47~48 | 주장 필수 필드와 반론 자료 필드를 잘못 작성했고, 이어 비어 있는 requirements로 거절됐다. |
| 호출 49 | 형식이 수락된 검수는 인용·법령 날짜 역할·시점·실제 부칙 조회 실패 등으로 blocked였다. |
| 호출 50 | 여전히 구별 자료의 direct 인용 모순, 존재하지 않는 공백 참조와 차단하지 않는 요건을 유보 근거로 쓴 오류가 남았다. |
| 호출 51~61 | 저장된 계획·본문 등을 다시 조회했다. 일부 요청은 선택 본문 수 초과 또는 없는 근거 참조로 거절됐다. |
| 호출 62~63 | 필수 requirements·citation.reason·후속 인용 등 누락, 빈 목록과 정의되지 않은 필드가 다시 나타나 형식 검사를 통과하지 못했다. 이후 시간 제한으로 종료했다. |

이는 관측된 수리 미완료 경로다. 하나의 서버 결함이 전체 시간 초과를 일으켰다고 단정하지 않는다. `inputDiagnostics.ts`는 필요한 자료형·허용값·최소/최대값을 안내하고, `research.ts`는 실행 중이 아닌 세션에 `answer_with_gaps`를 이미 제공한다. 그 안내가 존재한다는 사실과 모델이 실제로 복구·종료할 수 있다는 사실도 구별해야 한다.

최종 답변이 없으므로 최종 답변의 환각·허위 완료·불필요한 요건이 없었다고 판정하지 않는다. 해당 플래그는 `null`로 남기고 의미 실패를 기록한다. 마지막 중간 초안은 최종 출력의 대체물이 아니다.

다음 완료 경로 보완에는 실제 거절 입력과 마지막 유효 상태를 이용한 제한 재현이 필요하다. 유효했던 필드를 잃지 않고 현재 참조만 수정하도록 돕는 방법, 형식 오류와 근거 공백을 구별하고 정직한 미완료 답변으로 끝내는 방법을 먼저 설계해야 한다. 아직 새 수정의 효과나 원인을 확인했다고 하지 않는다. 시간·예산 연장, 필수 조건/인용 검사 완화, 실패 사례만 재실행하는 방식은 개선 근거로 사용하지 않는다.

## N-3. 사건 답변의 부연 규칙에서 적용 제외 누락

`remaining_two_homes-3`은 대표 판결을 번호 힌트 없이 찾고, 실제 본문·법령 버전을 읽어 핵심 2→3→2 전제를 올바르게 부정했다. 연·월 정밀도와 미래 개정 가능성을 보존하고 최종 검수의 blocked도 공개했다. blocked 자체가 이 시나리오의 실패 사유는 아니다.

다만 개정 설명에서 “양 주택이 조정대상지역인 경우 2년, 그 밖의 경우 3년”이라고 적었다. 실제 반환 조문에는 공고 전 취득 또는 계약·계약금 지급의 증빙이 있는 경우를 제1호에서 제외하는 괄호 규정이 있다. 양 주택이 조정지역이더라도 이 제외 조건을 충족하면 제2호의 3년인데, 요약은 2년으로 분류할 수 있다. 뒤의 전체 비과세 판단 제외 문구는 앞선 개별 기간 규칙의 범위를 바로잡지 않는다.

전체 최종 답변과 실제 반환 조문을 SSS에 대조한 [별도 판정](AUTHORITY_CASE_FIDELITY_SSS_RESPONSE_2026-10-02.txt)도 FAIL이다. 핵심 부정결론·실제 판례 발견·미완료 공개의 정확성은 인정하되, 부연 규칙의 중요한 적용조건 누락을 면제하지 않는다는 기준이다. 숫자나 출처 창작으로 과장하지 않으며 모든 요약 생략을 실패로 보는 것도 아니다.

이 결과는 단순 조회의 결과 근접 안내만으로 사건 답변의 모든 의미 오류를 해결했다고 주장할 수 없다는 근거다. 후속 검증은 질문에 필요하지 않은 기간·세율 등의 별도 법률 단정을 덧붙이는 경로와, 덧붙인 경우 적용 전제·예외가 보존되는지까지 포함해야 한다. 현재 구조 검수는 인용 일치·참조 관계를 확인하며 이 의미적 완전성을 인증하지 않는다.
