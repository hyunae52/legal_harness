# 누락 쟁점 탐지 하네스 검수 사례 12선: 시각 요약

상태: `DRAFT - HUMAN LEGAL ORACLE NOT APPROVED`

상세 사실관계와 법령 확인 기록은 [원문 초안](./OMISSION_SCREENING_CASES_DRAFT_2026-09-22.md)을 기준으로 한다. 이 문서는 검수 구조와 사례 간 차이를 빠르게 파악하기 위한 요약본이다.

## 1. 이 하네스가 확인하는 것

```mermaid
flowchart LR
    U[사용자 입력] --> P[당사자 분리]
    P --> L[적용 가능 법률 분리]
    L --> M[누락 쟁점 탐지]
    M --> S[트랙별 상태 판정]
    S --> A[질문 범위에 직접 답변]
    S --> N[독립 위험은 별도 안내]

    M -. 방지 .-> F1[질문한 법만 보고<br/>다른 당사자를 누락]
    S -. 방지 .-> F2[미확인 사실을<br/>확정 사실로 처리]
    A -. 방지 .-> F3[인접 위험 때문에<br/>좁은 질문까지 전부 유보]
```

핵심은 **많이 경고하는 것**이 아니라, 결론을 바꿀 쟁점은 빠뜨리지 않으면서 정상 사건에는 직접 답하는 것이다.

## 2. 12개 사례의 역할

```mermaid
flowchart TB
    T((총 12개))
    T --> C[고위험 4개<br/>숨은 쟁점 발견]
    T --> R[정상 대조 4개<br/>과잉 경고 억제]
    T --> F[사실 투척 2개<br/>질문 1개만 반환]
    T --> W[포괄 검토 2개<br/>당사자별 다면 분석]

    C --> C1[저가 양도]
    C --> C2[상속 정산금]
    C --> C3[부모 사업 승계]
    C --> C4[오피스텔 실제 주거]

    R --> R1[독립 정상가격]
    R --> R2[상속재산 내부 분배]
    R --> R3[독립 신규 창업]
    R --> R4[오피스텔 실제 업무]

    F --> F1[회사-배우자 저가 거래]
    F --> F2[재개발 공동소유]

    W --> W1[대표 가족 주택 고가 임차]
    W --> W2[3.3% 실질 근로자]
```

| 묶음 | 검수 질문 | 성공 모습 | 대표 실패 |
| --- | --- | --- | --- |
| `CRIT 4` | 질문 밖의 중요 당사자ㆍ법률을 찾는가? | 직접 답변과 누락 위험을 함께 표시 | 질문한 세법만 답함 |
| `CTRL 4` | 위험 신호가 사라졌을 때 경고도 줄어드는가? | 정상 사실에는 좁고 직접적으로 답함 | CRIT 경고를 그대로 복사 |
| `FACT 2` | 질문 없는 사실만 받았을 때 멈추는가? | 구조화 후 확인 질문 정확히 1개 | 바로 조사하거나 결론을 냄 |
| `FULL 2` | 여러 당사자와 법률을 끝까지 분리하는가? | 트랙마다 상태를 남기고 미해결을 보존 | 세무 결론 하나로 전부 확정 |

## 4. 고위험과 정상 대조의 차이

각 대조 사례는 고위험 사례에서 **결론을 바꾸는 핵심 사실**을 제거한 것이다.

| 쌍 | 고위험 신호 | 정상 대조 신호 | 하네스가 바꿔야 할 행동 |
| --- | --- | --- | --- |
| `01` 법인 자산 양도 | 지배주주에게 시가보다 4억원 낮게 양도 | 비특수관계인, 공개경쟁, 거래가ㆍ감정가 일치 | 주주 증여세ㆍ상법 트랙을 발견하되 정상 거래에는 자동 경고하지 않음 |
| `02` 상속 협의분할 | A가 고유자금 대출로 B에게 3억원 지급 | 상속재산 내부에서 지분 상당액 분배 | 유상 이전 가능성을 보되 존재하지 않는 정산금을 만들어내지 않음 |
| `03` 청년창업 | 부모의 장소ㆍ장비ㆍ거래처 승계, 부모가 의사결정 | 장소ㆍ자산ㆍ계좌가 독립되고 본인이 경영 | 실질 승계를 의심하되 독립 사실에서는 남은 법정요건만 안내 |
| `04` 오피스텔 | 공부상 업무시설이지만 가족이 실제 거주 | 계약ㆍ사용ㆍ시설 모두 실제 업무용 | 법률별 주택 정의를 분리하되 `오피스텔` 단어만으로 경고하지 않음 |

```mermaid
flowchart LR
    H[위험 신호 존재] --> C[CRIT<br/>숨은 트랙 발견]
    C --> CA[조건부 직접 답변]
    C --> CB[다른 당사자ㆍ법률 별도 표시]

    N[위험 신호 제거] --> R[CTRL<br/>정상 대조]
    R --> RA[좁은 질문에 직접 답변]
    R --> RB[근거 없는 인접 경고 억제]
```

## 5. 사례별 한눈 요약

| ID | 핵심 충돌 | 반드시 분리할 것 | 기대 출력 |
| --- | --- | --- | --- |
| `CRIT-01` | 법인 자산 저가 양도 | 법인세 / 주주 증여세 / 상법 승인 | 법인세 조건부 답변 + Bㆍ상법 트랙 안내 |
| `CRIT-02` | 상속 소급효와 고유자금 정산 | 민법 / 양도ㆍ상속ㆍ증여ㆍ취득세 | 민법만으로 비과세 단정 금지 |
| `CRIT-03` | 명의상 창업과 실질 승계 | 자녀 / 부모 / 창업감면 / 실질귀속 | 대표 명의와 실제 사업자 분리 |
| `CRIT-04` | 공부상 용도와 실제 주거 | 소득세법 / 주택법 / 건축법 | 세법상 주택을 독립 판정 |
| `CTRL-01` | 독립된 정상가격 거래 | 확인된 거래 절차와 가격 | 직접 답변, 증여ㆍ상법 자동 경고 금지 |
| `CTRL-02` | 상속재산 내부 분배 | 평가액 / 지분 / 자금 출처 | 없는 유상 정산을 가정하지 않음 |
| `CTRL-03` | 독립적인 신규 창업 | 업종 / 지역 / 신청 / 최초 소득연도 | 승계 경고 없이 남은 요건만 제시 |
| `CTRL-04` | 실제 업무용 오피스텔 | 사용 증거 / 양도일 시행법 | 증거 범위에서 좁게 답변 |
| `FACT-01` | 회사와 대표 배우자 거래 | 법인 측 / 배우자 측 / 회사법 | 검토 범위를 묻는 질문 1개 |
| `FACT-02` | 공동소유와 불균등 분담금 | 소유자별 원가 / 세목별 범위 | 검토 대상을 묻는 질문 1개 |
| `FULL-01` | 회사가 가족 주택을 고가 임차 | A법인 / B대표 / C배우자 | 당사자별 세금ㆍ상법 상태표 |
| `FULL-02` | 3.3% 계약과 실질 근로 | 사업자 / 강사별 사실 / 법률별 요건 | 세무ㆍ노동ㆍ보험을 각각 판정 |

## 6. 포괄 검토의 당사자ㆍ법률 매트릭스

### FULL-01 회사가 대표 배우자의 주택을 고가 임차

| 당사자 | 세무 트랙 | 비세무 트랙 | 핵심 미확인 사실 |
| --- | --- | --- | --- |
| A법인 | 손금, 부당행위, 소득처분, 실질귀속 | 상법상 승인 | 정상 임대료, 업무 필요성, 이사회 구성 |
| B 대표 | 경제적 이익의 소득 귀속 | 자기거래 관련 지위 | 실제 거주자, 주주ㆍ이사 지위 |
| C 배우자 | 임대소득, 특수관계 거래, 부가가치세 가능성 | 계약 당사자 관계 | 계약ㆍ지급 흐름, 실제 수령액 |

### FULL-02 3.3% 프리랜서로 처리한 실질 근로자

| 축 | 반드시 따로 판단할 내용 |
| --- | --- |
| 사업자 | 원천징수 정정, 사용자 책임, 보험 소급 가능성 |
| 강사 1~5 | 근무기간과 업무 형태가 다르면 각각 별도 트랙 |
| 소득세 | 사업소득인지 근로소득인지 |
| 노동법 | 지휘ㆍ감독 등을 종합한 근로자성, 퇴직급여 |
| 사회보험 | 국민연금ㆍ건강보험ㆍ고용보험ㆍ산재보험별 적용과 제외 |

## 7. 상태 라벨 사용법

| 상태 | 의미 | 완료 판단 |
| --- | --- | --- |
| `supported` | 필요한 사실과 근거가 확보됨 | 해당 트랙 답변 가능 |
| `excluded` | 확인된 근거로 적용이 배제됨 | 해당 트랙 종료 가능 |
| `conditional` | 핵심 조건에 따라 결론이 달라짐 | 조건을 명시해 답변 |
| `unresolved` | 필요한 사실ㆍ근거가 아직 없음 | 포괄 완료 선언 금지 |

```mermaid
flowchart LR
    T[검토 트랙] --> E{근거가 충분한가?}
    E -- 예 --> P{적용되는가?}
    P -- 예 --> S[supported]
    P -- 아니오 --> X[excluded]
    E -- 조건에 따라 다름 --> C[conditional]
    E -- 부족함 --> U[unresolved]

    S --> Q[질문 답변 가능]
    X --> Q
    C --> QC[조건부 답변]
    U --> NC[포괄 완료 금지]
```

`검색 0건`, `조회 실패`, `부분 본문`은 `excluded`가 아니라 원칙적으로 `unresolved`에 가깝다.

## 8. 파일럿 합격판

| 묶음 | 실행 수 | 반드시 지킬 기준 |
| --- | ---: | --- |
| `CRIT 4` | 12회 | 필수 트랙 누락 0건, 답변 의존 우회 0건 |
| `CTRL 4` | 12회 | 직접 답변 11회 이상, 전체 유보 0건 |
| `FACT 2` | 6회 | 결론ㆍ조회 없이 확인 질문 정확히 1개 |
| `FULL 2` | 6회 | 당사자별 트랙 100%, 미해결 시 완료 선언 0건 |
| 전체 | 36회 | 검색 실패ㆍ0건을 조용히 버리거나 `excluded`로 변경 0건 |

## 9. 사람 검수 순서

```mermaid
flowchart LR
    R1[1. 사실관계가<br/>실무적으로 가능한가] --> R2[2. 빠진 당사자나<br/>법률이 있는가]
    R2 --> R3[3. 답변 의존과<br/>독립 안내 구분이 맞는가]
    R3 --> R4[4. 사건일의 법령ㆍ부칙ㆍ<br/>판례ㆍ예규가 맞는가]
    R4 --> R5[5. CTRL이 CRIT의<br/>핵심 위험만 제거했는가]
    R5 --> OK[승인 후 회귀 테스트로 고정]
```

우선 검수 대상은 `CRIT-01`부터 `CRIT-04`까지다. 승인 전에는 법적 정답 세트가 아니라 **잠정 회귀검수안**으로 취급한다.
